# Утро Жени — публичный виджет

Этот репозиторий **sssneer124-maker/utro-zheni-feed.** публичный. Не размещать здесь личные планы, адреса, смены и данные из Notion.

- `feed.json` — безопасная сводка, которую читает виджет. Сейчас в статусе `setup`.
- `index.html` — опциональная страница для GitHub Pages.
- `scriptable-widget.js` — код для Scriptable на iPhone. Адрес уже указан в коде, а источник настроится сам при первом запуске.

Адрес JSON: https://raw.githubusercontent.com/sssneer124-maker/utro-zheni-feed./main/feed.json

Доступ ChatGPT к этому отдельному репозиторию ограничен. Публичный feed.json не содержит персональных планов.
Полная личная газета отдельно поступает по Gmail.

Ссылку на GitHub Pages нельзя считать работающей, пока страницы не включены в Settings → Pages.
